This folder will hold dated evidence that does not belong with final media: design reviews, calibration records, test summaries, and change records.

> [!CAUTION]
> **Current status: Reserved.** Do not add simulations, predictions, or concept renders as physical-test evidence.

For every record, state the date, what was observed, the configuration used, and the next action.
