## Project Overview

This repository contains the development of our autonomous vehicle for the World Robot Olympiad (WRO) Future Engineers 2026 competition.

The objective of the challenge is to design, build, program, and document a self-driving vehicle capable of navigating the WRO Future Engineers track autonomously. The vehicle must complete both the Open Challenge and the Obstacle Challenge while adapting to randomized track configurations.

The project is currently in the initial development phase. Future updates will include hardware design, software architecture, testing procedures, competition strategy, and engineering documentation.

---

## Development Goals

### Mechanical System

* Design a stable four-wheeled vehicle
* Implement an efficient steering mechanism
* Optimize weight distribution
* Ensure compliance with WRO size and weight regulations

### Electronics

* Select appropriate controllers and sensors
* Integrate power management systems
* Develop reliable communication between components

### Software

* Autonomous navigation
* Sensor fusion
* Computer vision
* Obstacle detection and avoidance
* Parking algorithms
* Lap counting and track localization
