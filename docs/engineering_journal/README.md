# Engineering journal

Create one Markdown file per meaningful design decision, investigation, or iteration. Use a date in the filename, for example `2026-08-12-steering-layout.md`.

Each entry should include the date and author, the problem, options considered, the reason for the chosen direction, the available evidence, and the next action. Clearly label evidence as calculation, simulation, observation, or measured test result.

Do not record a proposed result as a completed test result.
