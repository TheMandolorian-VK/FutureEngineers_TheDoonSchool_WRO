# Engineering Journal

**A chronological record of decisions, iterations, and lessons.**

[← Documentation](../README.md) · [Testing](../testing/README.md)

</div>

---

Create one Markdown file per meaningful design decision, investigation, or iteration. Use a date in the filename, for example `2026-08-12-steering-layout.md`.

Each entry should include the date and author, the problem, options considered, the reason for the chosen direction, available evidence, and next action. Clearly label evidence as **calculation**, **simulation**, **observation**, or **measured test result**.

> [!IMPORTANT]
> Do not record a proposed result as a completed test result.
